\# AI-News-Agent





\## 项目介绍



AI-News-Agent 是一个基于 Python 的智能新闻处理项目。



目标：



\- 自动获取新闻数据

\- 对新闻进行整理

\- 使用 AI 进行分析总结

\- 生成结构化新闻报告





\## 技术栈



目前使用：



\- Python

\- Git

\- Linux

\- 虚拟环境





后续计划：



\- requests 爬虫

\- BeautifulSoup 数据解析

\- 大语言模型 API

\- 自动新闻摘要
